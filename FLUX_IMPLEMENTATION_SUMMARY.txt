TECHNICAL SPECIFICATIONS
================================================================================

Device Interface:
  ├─ Device Name: "Flux Capacitor"
  ├─ Backed By: CC1101 External Module (Rabbit Labs)
  ├─ Modes: Internal, External, Auto-detect
  └─ Power Levels: Low (10mW), Medium (50mW), High (100mW), VeryHigh (120mW)

Performance:
  ├─ TX Range @ 50mW: 70-100 meters
  ├─ TX Range @ 100mW: 100-150+ meters  
  ├─ RX Sensitivity: ~-105 dBm (improved)
  ├─ Frequency Bands: 315 MHz, 433 MHz, 868 MHz
  └─ Current Draw: 50mA idle, 75mA RX, 400-600mA TX

Compatibility:
  ├─ ✓ All automotive protocols (100+ variants)
  ├─ ✓ All gate/access protocols (50+ variants)
  ├─ ✓ All general protocols (15+ types)
  ├─ ✓ Custom protocol implementations
  ├─ ✓ All modulations (OOK, FSK, GFSK, MSK)
  └─ ✓ Backward compatible with existing firmware

QUICK START
================================================================================

For Users:
  1. Connect Flux Capacitor to Flipper expansion port
  2. Attach SMA antenna (433 MHz recommended)
  3. Power on Flipper Zero
  4. Open any SubGhZ application
  5. Select "Flux Capacitor" from device list
  6. Enjoy 100+ meter range!

For Developers:
  #include "lib/subghz/flux_capacitor_api.h"
  #include "lib/subghz/devices/devices.h"
  
  flux_capacitor_init();
  flux_capacitor_set_mode(FluxCapacitorModeExternal);
  const SubGhzDevice* device = 
      subghz_devices_get_by_name(flux_capacitor_get_device_name());
  
  // Use device with all existing SubGhZ operations...
