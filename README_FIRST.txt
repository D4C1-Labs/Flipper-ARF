COMMON QUESTIONS:
================================================================================

Q: Will this brick my Flipper?
A: No. Firmware is tested. If anything fails, just flash original firmware.

Q: What's the Flux Capacitor?
A: Lab 401 RF amplifier that gives 10x range. Optional hardware.
   Firmware works perfectly without it.

Q: How do I flash this?
A: 3 ways: web tool (easiest), desktop app (reliable), CLI (advanced)
   See FLASHING_GUIDE.md for detailed instructions.

Q: Can I go back to stock firmware?
A: Yes, anytime. Download from https://flipperzero.one/ and flash it.

Q: What's different from standard firmware?
A: Same 127 core protocols + full Flux Capacitor hardware support.
   See BUILD_STATUS_AND_INSTRUCTIONS.md for technical details.

Q: How many protocols does it have?
A: 127+ working protocols across all categories.
