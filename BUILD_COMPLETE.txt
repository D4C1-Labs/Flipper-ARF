FLASHING INSTRUCTIONS

Choose ONE method below:

METHOD 1: Web Flashing (Easiest - No Software Required)
────────────────────────────────────────────────────────
1. Visit: https://lab.flipper.net/
2. Connect Flipper Zero via USB
3. Select "FLIPPER_FIRMWARE_WITH_FLUX_CAPACITOR.dfu"
4. Click "Flash"

METHOD 2: qFlipper Desktop App
──────────────────────────────
1. Download from: https://flipperzero.one
2. Put Flipper in DFU mode (hold LEFT+BACK, power on)
3. Open qFlipper → "Reinstall Firmware"
4. Select DFU file
5. Wait for completion

METHOD 3: Command Line (dfu-util)
─────────────────────────────────
# Ubuntu/Debian:
sudo apt install dfu-util
sudo dfu-util -d 0483:df11 -a 0 -D FLIPPER_FIRMWARE_WITH_FLUX_CAPACITOR.dfu

# macOS:
brew install dfu-util
dfu-util -d 0483:df11 -a 0 -D FLIPPER_FIRMWARE_WITH_FLUX_CAPACITOR.dfu

PUT FLIPPER IN DFU MODE FIRST:
  1. Power off completely
  2. Hold LEFT + BACK buttons
  3. Press power button (don't release)
  4. Wait 5 seconds until "DFU" appears on screen
  5. Release buttons

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: DFU Mode Not Showing
Solution: 
  • Use a different USB cable
  • Make sure Flipper is fully powered off
  • Hold buttons BEFORE powering on
  • Wait until "DFU" text appears

Problem: Flashing Fails
Solution:
  • Close all other USB apps
  • Try a different USB port
  • Restart computer and try again
  • Use USB 3.0 port if available

Problem: Flux Capacitor Not in Menu
Solution:
  • Re-run flashing process
  • Make sure file is FLIPPER_FIRMWARE_WITH_FLUX_CAPACITOR.dfu
  • Check you're in Sub-GHz → Transmit menu
  • Restart Flipper (power off/on)
