## 🚀 Quick Reference

### Three Ways to Flash

1. **Web Flashing** (Easiest)
   - Go to https://lab.flipper.net
   - Upload DFU file
   - Flash

2. **Desktop App**
   - Download qFlipper
   - Update → Reinstall Firmware
   - Select DFU file

3. **Command Line**
   - `dfu-util -d 0483:df11 -a 0 -D flipper-z-f7-cvmr-lab.dfu`

### Enter DFU Mode
- Hold LEFT + BACK
- Press POWER
- Wait for bootloader screen

### Verify Success
- Go to Sub-GHz → Transmit
- Look for "Flux Capacitor"
- If there ✅ = All working!
